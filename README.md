>
> It is kept as a portfolio snapshot and is not the chapter's official website.

## Features

- Responsive pages for chapter information, officers, events, and projects
- Filterable upcoming and past events
- Original Prisma and SQLite event-management system with authenticated admin tools
- Reusable cards, navigation, and animated interface components
- SEO metadata and optimized images

## Development

```bash
pnpm install
pnpm dev
```

No environment variables are required.
